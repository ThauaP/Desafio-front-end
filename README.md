 Frontend Mentor - Order Summary Card

Solução para o desafio Order Summary Card do Frontend Mentor: um card de resumo de pedido, responsivo, construído com HTML e CSS puro.


 Construído com

- HTML5 semântico
- CSS3 (Flexbox)
- Mobile-first / Media queries
- Google Fonts (Red Hat Display)

 O que aprendi

- Alinhar ícone, texto e link numa mesma linha com Flexbox, usando margin-right: auto pra empurrar o link pra ponta.
- Fazer a imagem de fundo acompanhar a largura da tela com background-size: 100% auto, trocando entre versão mobile e desktop via media query.
- Desbugar CSS que quebra por conteúdo inválido.
